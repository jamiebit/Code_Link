### How It Works

The application is built around a **swipe-based mechanism** that allows users to either accept or reject projects. Users can swipe through available project ideas, or upload their own ideas to make them visible to others.

- If a user swipes right on a project, it signals interest.
- The **project owner** is notified and can choose to accept or decline the request.
- Once accepted, the project moves to the user's **ongoing projects** list.

This encourages **collaborative project discovery** and helps users find like-minded developers to work with.
